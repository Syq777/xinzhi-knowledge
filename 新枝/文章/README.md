## 归档规则

- 优先按文章核心主题归位，不按发布平台
- 同时符合多个主题时，放在最能代表主旨的目录
- 即刻 App / 微信公众平台 / b 站 / x.com / 小红书等纯链接性页面统一进 `15_网页索引与碎片`
- 重名或疑似重复文章不直接删除，统一进入 `99_待核查/01_重复待确认`
- 二级目录命名 `数字_主题`，保持稳定，新增主题用增量编号

## 维护建议

- 新文章先看是否能归入现有子目录；新主题超过 5 篇再考虑开新子目录
- 子目录数量长期失衡时（>50 或 <3），可考虑拆分或合并
- 每季度回顾一次 `15_网页索引与碎片`，把有价值的内容迁出
