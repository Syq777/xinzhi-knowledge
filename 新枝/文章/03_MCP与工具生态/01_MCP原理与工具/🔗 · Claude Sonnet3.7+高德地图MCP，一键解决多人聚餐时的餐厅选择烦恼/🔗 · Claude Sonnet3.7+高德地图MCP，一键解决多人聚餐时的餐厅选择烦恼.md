01 背景

周五看到AI产品黄叔用高德地图MCP做出行旅游攻略的教程，迅速复刻了一遍，效果特别好，这意味着Agent具备处理用户复杂需求，并调用工具生成对应方案的能力。

随后我代入产品的视角想，身边什么与地理位置相关的问题，可以用“语言模型解析需求+查询地点”的方式解决呢？

我想到了我周末要去的一个朋友聚会，作为组织者，选择餐厅的流程长且复杂：

1. 根据住处确定餐厅范围/所在商圈：

A的住处在A，朋友B住处在B，朋友C住处在C，打开地图输入位置后，在地图上确定ABC中点的大致位置；

2. 查询商圈对应餐厅并挑选：

打开大众点评/美团APP，挑选餐厅，列出待定地点。这个选择的动作需要考虑聚会需求和参加者的偏好：比如朋友聚会可以去路边摊吃烧烤，商务宴请则要高档有特色，接待客人要选地方特色菜馆；请比自己地位更高的人吃饭，为了表示尊敬，也要以对方的出行方便、口味偏好为先。

3. 发送群里，复查交通：让朋友们确认自己是否方便到达、是否可以接受口味；

4. 更新地点：如果朋友们都觉得交通/价格不合适，需要重新选择地点。

过往的Graph UI界面设计只给用户提供了根据需求自行选择的入口，通过优化入口排序和UI设计提升搜索效率，提升用户选择的效率，无法更进一步。

使用大语言模型+MCP构建一个agent，看起来可以丝滑解决这个问题。

03 过程

此工具搭建几乎无开发难度，和技术门槛，重要的是写提示词和产品搭建的思路，还有中间的一些细节调试。

在这里我仅分享下我的构建思路：

1. 思考在预定餐厅时，用户一般会考虑什么东西，其中有什么要素，并以编程中“类”的思路定义。我认为餐厅选择任务的核心是“人”和“餐厅”，因此：

（1）定义“人”

```
    class 个人画像:
        """
        定义就餐者的个人特征和偏好
        """
        class 个人属性:
            昵称: str  # 用户希望被称呼的名称
            性别: str  # 用户性别
            身份: str  # 用户的社会身份或职业
            星标: boolean #用户是否是重要人物，需要特殊考虑
        
        class 出行相关:
            地理位置: str  # 用户当前或常住地理位置
            出行习惯: list[str]  # 用户的出行方式偏好、习惯等
        
        class 饮食相关:
            口味: list[str] = ["少油少盐", ...]  # 用户口味偏好
            菜系: list[str]  # 用户喜欢的菜系
            忌口: list[str] = ["不吃刺身", "无法吃辣", "不吃鸡肉/猪肉"，...]  # 用户的饮食禁忌
            消费水平: str  # 用户的饮食消费水平
        
        class 其他:
            生活习惯或偏好: list[str] = ["健身", ...]  # 用户的其他生活习惯或偏好
```

（2）定义“餐厅”

```
 class 餐厅属性:
        地理位置属性
            地址: str  # 目的地的地址
            POI：str #目的地的POI数据，例如“116.485487,39.975520”
        餐饮属性: dict = {
            "业态类型": ["咖啡厅", "下午茶", "餐厅", "酒吧",],  # 目的地可提供的餐饮类型
            "人均消费水平": str,  # 目的地的餐饮消费水平
            "特色菜品": list[str],  # 目的地的特色菜品
            "营业时间": str  # 餐饮场所的营业时间
            "特色Tag": list[str] # 目的地的2~4字特色标签，你可以根据理解自己生成
        }
```

2. 人在进行餐厅初筛时，通常依据什么制定策略，什么因素是会最被优先考虑的？

显然，聚餐的需求被满足是第一位的，随后，是选择符合大多数人偏好且方便出行。我根据这个思路撰写了提示词，要求模型结合这三个关键点，生成地点搜索关键词后再调用MCP搜索地点。

```
def 餐厅搜索关键词(用户列表, 聚会期望):
    """基于用户信息和聚会目的生成餐厅搜索关键词"""
    # 初始化结果
        搜索关键词列表 = []
        
        # 读取用户信息
        用户身份标签 = 用户.个人属性.身份
        用户星标标签 = 用户.个人属性.星标
        用户其他信息 = 用户.其他.生活习惯或偏好
        # 读取聚餐组织者目的
        聚会期望 = 期望.聚会期望
        # 运用LLM能力生成MCP搜索关键词
        搜索关键词列表 = 搜索关键词列表.append("提示词1"， "提示词2", ..., "提示词n")
        # 返回一个搜索关键词列表，数量不限，以满足组织者需求为优
        return 搜索关键词列表
```

3. MCP返回地点列表后，需要根据策略判断餐厅推荐指数，根据指数结果重排推荐结果。

我从业态匹配度、消费匹配度、菜品匹配度、位置评估四个角度入手设计策略，并在综合得分计算上调整权重构建最终的策略：

```
    def 评估餐厅匹配度(self, 餐厅):
        """综合评估餐厅的各项指标与用户群体的匹配程度"""
        # 1. 检查业态类型是否符合预计聚会时间
        业态匹配度 = self._计算业态匹配度(餐厅.餐饮属性["业态类型"], self.预计聚会时间)
        
        # 2. 评估消费水平匹配度
        消费匹配度 = self._计算消费匹配度(餐厅.餐饮属性["人均消费水平"])
        
        # 3. 评估特色菜品与用户口味的匹配度
        菜品匹配度 = self._计算菜品匹配度(餐厅.餐饮属性["特色菜品"])
        
        # 4. 综合位置便利度
        位置评估 = self.评估目的地位置策略(餐厅)
        
        # 5. 计算综合得分
        if 业态匹配度 < 2:
            综合得分 = 0
        else：
            综合得分 = (业态匹配度 * 0.2 + 
                    消费匹配度 * 0.2 + 
                    菜品匹配度 * 0.1 + 
                    位置评估["加权便利度"] * 0.5)
            
        return {
            "餐厅": 餐厅,
            "综合得分": 综合得分,
            "业态匹配度": 业态匹配度,
            "消费匹配度": 消费匹配度,
            "菜品匹配度": 菜品匹配度,
            "位置便利度": 位置评估,
            "用户交通详情": 位置评估["用户便利度详情"]
        } 
```

4. 各项指标的具体计算方式：

（1）业态匹配度

```
    def _计算业态匹配度(self, 业态类型, 预计聚会时间):
        """根据预计聚会时间和餐厅业态类型计算匹配度"""
        时间业态映射 = {
            "早茶": ["茶楼", "咖啡厅", "早餐店"],
            "中餐": ["餐厅", "食堂", "快餐店"],
            "晚餐": ["餐厅", "酒楼"],
            "夜宵": ["夜宵店", "酒吧", "小吃店"]
        }
        
        推荐业态 = 时间业态映射.get(预计聚会时间, [])
        匹配项 = set(业态类型) & set(推荐业态)
        
        return len(匹配项) / max(len(推荐业态), 1) * 10  # 0-10分
```

（2）消费匹配度

```
    def _计算消费匹配度(self, 餐厅消费水平):
        """计算餐厅消费水平与用户期望的匹配度"""
        # 检查是否有星标(VIP)用户
        星标用户 = [用户 for 用户 in self.用户列表 if self._是否星标用户(用户)]
        
        if 星标用户:
            # 以星标用户的消费水平为准
            期望消费水平 = 星标用户[0].饮食相关.消费水平
        else:
            # 以多数人的消费水平为准
            消费水平计数 = {}
            for 用户 in self.用户列表:
                水平 = 用户.饮食相关.消费水平
                消费水平计数[水平] = 消费水平计数.get(水平, 0) + 1
            
            期望消费水平 = max(消费水平计数.items(), key=lambda x: x[1])[0]
```

（3）菜品匹配度

```
    def _计算菜品匹配度(self, 特色菜品):
        """计算餐厅特色菜品与用户口味/忌口的匹配度"""
        用户口味列表 = [用户.饮食相关.口味 for 用户 in self.用户列表]
        用户菜系列表 = [用户.饮食相关.菜系 for 用户 in self.用户列表]
        用户忌口列表 = [用户.饮食相关.忌口 for 用户 in self.用户列表]
        
        # 统计所有用户的口味偏好
        口味偏好统计 = {}
        for 口味列表 in 用户口味列表:
            for 口味 in 口味列表:
                口味偏好统计[口味] = 口味偏好统计.get(口味, 0) + 1
        
        # 统计所有用户的菜系偏好
        菜系偏好统计 = {}
        for 菜系列表 in 用户菜系列表:
            for 菜系 in 菜系列表:
                菜系偏好统计[菜系] = 菜系偏好统计.get(菜系, 0) + 1
        
        # 统计所有用户的忌口
        忌口统计 = {}
        for 忌口列表 in 用户忌口列表:
            for 忌口 in 忌口列表:
                忌口统计[忌口] = 忌口统计.get(忌口, 0) + 1
        
        # 计算匹配度
        匹配分数 = 0
        忌口冲突 = 0
        
        for 菜品 in 特色菜品:
            # 检查菜品是否满足主流口味偏好
            for 口味, 人数 in 口味偏好统计.items():
                if self._菜品符合口味(菜品, 口味):
                    匹配分数 += 人数 / len(self.用户列表)
            
            # 检查菜品是否属于用户偏好的菜系
            for 菜系, 人数 in 菜系偏好统计.items():
                if self._菜品属于菜系(菜品, 菜系):
                    匹配分数 += 人数 / len(self.用户列表)
            
            # 检查菜品是否与用户忌口冲突
            for 忌口项, 人数 in 忌口统计.items():
                if self._菜品违反忌口(菜品, 忌口项):
                    忌口冲突 += 人数 / len(self.用户列表)
        
        # 计算最终得分(0-10分)
        最终得分 = min(10, 匹配分数 * 2) - min(10, 忌口冲突 * 4)
        return max(0, 最终得分)
```

（4）位置便利性评估

```
    def 评估目的地位置策略(self, 餐厅):
        """根据所有用户的职位和便利度，综合评估餐厅位置的适合度"""
        用户便利度列表 = []
        
        for 用户 in self.用户列表:
            出行信息 = self.计算个人出行时间(用户, 餐厅)
            职位权重 = self._获取职位权重(用户.个人属性.身份)
            
            用户便利度列表.append({
                "用户": 用户,
                "便利度": 出行信息["便利度"],
                "权重": 职位权重,
                "交通信息": 出行信息
            })
        
        # 计算加权总便利度
        加权便利度 = sum(item["便利度"] * item["权重"] for item in 用户便利度列表)
        
        return {
            "加权便利度": 加权便利度,
            "用户便利度详情": 用户便利度列表
        }
       
      
```

        """生成最终的餐厅推荐列表(限制为3个)""" #实际应用中可以根据自己需求修改
        所有评估结果 = []
        
        for 餐厅 in self.候选餐厅列表:
            评估结果 = self.评估餐厅匹配度(餐厅)
            所有评估结果.append(评估结果)
        
        # 按综合得分排序
        所有评估结果.sort(key=lambda x: x["综合得分"], reverse=True)
        
        # 取前三名
        self.最终推荐列表 = 所有评估结果[:3]
        return self.最终推荐列表
