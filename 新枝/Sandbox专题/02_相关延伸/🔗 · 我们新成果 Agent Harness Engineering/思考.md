这是一篇关于 Agent Harness Engineering 的综述。这篇论文主要梳理了整个 Agent 的发展历史，以及它是如何一步步演进到 Harness 状态的。

论文提出了一个框架，将其划分为七层结构：

1. 执行层 (Execution Layer)
   主要关注代码的运行环境，例如有的在本地跑，有的则引入了 Sandbox（沙箱）的概念。

2. 工具接口 (Tool Layer)
   包括 Skill、MCP (Model Context Protocol) 以及其他各种工具接口。

3. 上下文管理 (Context Management)
   主要解决模型在每一步能“看到”什么，其中涵盖了 Memory（记忆）和 RAG。

4. 控制流 (Control Flow)
   涉及操作的读写，即如何设计 Agent 的架构或执行模式（比如 ReAct 模式，以及并行或串行等方式）。

控制平面则由以下三层组成：
(a) 可观测性 (Observability)：包括 Trace 和 Failure 追踪。
(b) 验证与评估 (Verification)：针对任务进行验证、评估、归因及反馈。
(c) 治理 (Governance)：涉及权限管理、政策、Identity（身份验证）等。

总的来说，这篇论文虽然没有创造全新的概念，但它完整地梳理了从 Agent 到 Harness 的约束条件和应用环境，为读者提供了一个全局的认知。
